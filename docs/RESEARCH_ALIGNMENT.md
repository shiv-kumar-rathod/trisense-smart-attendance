# Research Alignment

The reference paper describes image acquisition, preprocessing, face detection,
feature extraction, training/classification and attendance storage. It uses
Viola-Jones for detection and LBPH for feature extraction, with Python/OpenCV and
Excel reporting.

Our one-month implementation plan uses a pre-trained face-recognition approach rather
than training a large neural network from scratch. The reference paper's limitations
remain important for testing: lighting, pose, expression and environment can reduce
recognition performance.

The final paper should distinguish:
1. literature/reference methodology,
2. implemented system,
3. measured experimental results,
4. limitations and future improvements.
